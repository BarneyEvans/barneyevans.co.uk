# Warm / Duo A

Two self-contained homepage concepts. Open either index.html directly; there is no install or build step.

- [A1 — A good thread](A1-good-thread/index.html): lilac cloth, raspberry stitching and equal portrait medallions.
- [A2 — Little by little](A2-little-by-little/index.html): blue ink, apricot crayon and an open illustrated spread.

Each concept includes its own photos, local Nunito and DM Sans fonts (with OFL licences), CSS and dependency-free SVG motion. Read its pitch.md for the scroll story and final QA evidence. All factual text comes from company/copy-v3.md. Dotted underlines mark the working name and unconfirmed details.

The scout report informed the continuous illustrated spreads (Storyboat / Pillowbook), recurring drawing language (Gucha Gucha / Form Play), and textile journey (Swash case study). References with limited visual verification in the scout report were not treated as verified interaction precedents.

Optional verification: set PLAYWRIGHT_MODULE to the installed Playwright module and run node design/concepts/v3/warm/verify.cjs from the repository root. It uses installed Chrome in headless mode and saves screenshots to the operating-system temporary folder, never to this repository. verification.json records layout, image and script checks at 320, 390 and 1440 pixels; the motion partner's report records interaction and throttled timing evidence.
