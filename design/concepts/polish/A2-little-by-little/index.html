How Barney’s lessons work

Little by little.

“We move at the speed the student needs to fully understand.”

— Barney Evans

My lessons feature real-time document collaboration, allowing students to actively participate rather than passively watch.

Every lesson is built with a custom set of slides tailored to the current topic and progress which can be used for recap at a later stage.

Rather than memorisation, I emphasise understanding core concepts and developing problem-solving skills that will serve you beyond exams.
